# Todo Web

A simple browser-based todo app built with HTML, CSS, and JavaScript.

## Features

- Add new todo items
- Mark todos as complete
- Remove todos from the list
- Simple, responsive UI

## Files

- `index.html` — app structure
- `style.css` — app styling
- `script.js` — todo behavior and interactions

## Usage

1. Open `index.html` in your browser.
2. Add a todo item.
3. Mark it complete or delete it when done.

## Notes

This is a lightweight project for practicing vanilla web development.
